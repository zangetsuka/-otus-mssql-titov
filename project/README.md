# База данных PrinterTrack

**PrinterTrack** — это база данных, предназначенная для управления ресурсами организации, такими как принтеры, расходные материалы и сотрудники, закрепленные за различными отделами.

## Возможности

1. **Управление сотрудниками**:  
   - Хранение информации о сотрудниках, их должностях и закрепленных отделах.

2. **Управление принтерами**:  
   - Учет принтеров, их моделей, местоположения (отделов) и IP-адресов.

3. **Учет расходных материалов**:  
   - Управление расходными материалами (картриджи, фотобарабаны) и их привязка к конкретным принтерам.

4. **Структура отделов и организаций**:  
   - Организация сотрудников и ресурсов по отделам и организациям.

5. **Функции и процедуры**:  
   - **CheckConsumableExists**: Проверяет наличие определенного расходного материала для принтера в отделе.  
   - **GetTotalConsumables**: Подсчитывает общее количество расходных материалов для принтера в отделе.  
   - **GetOrganizationByDepartment**: Определяет организацию, которой принадлежит отдел.

## Таблицы

- **Сотрудник**: Информация о сотрудниках.  
- **Принтер**: Учет принтеров.  
- **Расходные_материалы**: Учет расходных материалов по типу и количеству.  
- **Отдел**: Связь отделов с организациями.  
- **Организация**: Данные об организациях.  
- **Названия_Отделов**: Нормализованные названия отделов.
